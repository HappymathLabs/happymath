# 获奖论文风格参考索引

撰写完整论文或重要章节前，按语言读取对应获奖论文示例。示例只用于学习各模块的组织方式、叙述节奏、图表与文字配合方式，不复制题目内容、数据、结论或表达。

这些 `.md` 文件由 PDF 转换而来，可能存在标题层级、公式、图片、表格或换行错误。遇到明显格式错误时忽略转换噪声，以原论文模块的写作逻辑和风格为参考。

## 国赛示例

- 国赛示例 1：`references/CUMCM_Prized_Papers/CUMCM_2023_B_B226/CUMCM_2023_B_B226.md`
- 国赛示例 2：`references/CUMCM_Prized_Papers/CUMCM_2023_C_C228/CUMCM_2023_C_C228.md`

参考重点：
- 摘要如何按问题概括方法、结果和关键数据，且不放公式、图表或引用。
- 问题重述与问题分析如何区分：问题分析只做题面信息、约束条件和解题思路分析，不提前写灵敏度分析、模型检验或结果评价。
- 模型建立与求解中公式、算法、流程图、结果表述的衔接方式。
- 模型评价、改进与推广中优点、缺点、改进、推广各小点的具体写法。

## 美赛示例

- 美赛示例 1：`references/MCM_ICM_Prized_Papers/MCM_ICM_2025_A_2500836/MCM_ICM_2025_A_2500836.md`
- 美赛示例 2：`references/MCM_ICM_Prized_Papers/MCM_ICM_2025_C_2507817/MCM_ICM_2025_C_2507817.md`

参考重点：
- Summary 如何以自然段凝练问题、方法、结果和结论，避免公式、图表和引用。
- Introduction / Restatement / Our Work 如何承接赛题背景并引出建模框架。
- Assumptions and Justifications 如何将假设与合理性一一对应。
- Model sections 如何组织模型建立、求解、结果分析和图表解释。
- Sensitivity Analysis、Model Evaluation、Further Discussion 如何放在独立章节，而不是混入 Problem Analysis 或 Introduction。
