# 国赛单个问题撰写规范

本文档规定国赛论文中「每个具体问题」的撰写方式。每个问题都必须拆分为 **理论内容** 与 **结果内容** 两部分。

## 1. 整体结构

在每个问题的章节下，使用两个小节：

```markdown
## 问题一模型的建立与求解

### 理论内容

（建模思路、方法介绍、流程图/算法流程图/算法文字图）

### 结果内容

（求解结果、数据可视化、结果分析）
```

标题可根据实际内容调整，例如「问题一：基于某方法的某分析」也可接受，但内部仍需保持「理论 + 结果」结构。

## 2. 理论内容

### 2.1 写作目标

用简洁、精炼、可视化的方式介绍解决该问题所使用的主要方法。把求解思路以清晰、直观的形式描述出来，使评阅老师快速理解你的建模逻辑。

### 2.2 必含元素

- **方法概述**：1-2 段说明本题采用什么模型/方法，为什么选择它。
- **核心公式**：保留能体现模型本质的 1-3 个关键公式。
- **可视化图表**：
  - 建模流程或方法流程 → 流程图
  - 算法运行路径 → 算法流程图
  - 算法伪代码或算法步骤 → 算法文字图（三线表）
- 图表绘制前必须阅读 `cn_theory_chart_guide.md`。

### 2.3 写作原则

- 不堆砌大量公式和定义。
- 不复制教科书式长篇推导。
- 重点放在「我如何用这个模型解决本题」。
- 每个图表都要有对应的文字说明，解释图表在整体思路中的作用。

### 2.4 示例结构

```markdown
### 理论内容

针对问题一，我们将题目中的某现象抽象为某类优化问题。首先，定义决策变量；其次，根据题目约束建立目标函数；最后，采用某算法求解。

决策变量定义如下：

$$x_i = \cdots$$

目标函数为：

$$\min Z = \cdots$$

求解流程如图 1-1 所示。

![图 1-1 问题一求解流程图](images/problem1_flow.png)

由图 1-1 可知，整个求解过程分为三步：……

算法步骤如表 1-1 所示。

表 1-1  遗传算法求解步骤

| 步骤 | 操作 |
|------|------|
| 1 | 初始化种群和算法参数 |
| 2 | 计算个体适应度并执行遗传操作 |
| 3 | 判断是否满足终止条件并输出最优方案 |
```

## 3. 结果内容

### 3.1 写作目标

以简洁、精炼的形式呈现本题求解或分析结果。结果内容必须是理论内容的实践，展示模型实际运行后得到的数据、结论与洞察。

### 3.2 必含元素

- **数据/结果呈现**：使用表格、折线图、柱状图、散点图、热力图等。
- **结果分析**：每张图表后必须紧跟一段分析文字，解释图表说明了什么、结果是否符合预期、对问题有何回答。
- **可视化图表**：
  - 禁止使用流程图、算法图。
  - 只能使用对结果本身进行可视化的图表。
- 图表绘制前必须阅读 `cn_result_chart_guide.md`。

### 3.3 写作原则

- 结果与分析一一对应。
- 不要只放数据表格而不解释。
- 不要只放图片而没有结论。
- 突出对问题的直接回答。

### 3.4 示例结构

```markdown
### 结果内容

采用上述模型对问题进行求解，得到各方案的评价结果如表 1-1 所示。

表 1-1  各方案评价结果

| 方案 | 得分 | 排名 |
|------|------|------|
| A    | 0.85 | 1    |
| B    | 0.72 | 2    |

从表 1-1 可以看出，方案 A 的得分最高。进一步地，图 1-2 展示了不同参数下方案 A 的稳定性。

![图 1-2 参数灵敏度分析结果](images/problem1_sensitivity.png)

由图 1-2 可知，当参数在 [0.5, 1.5] 范围内变化时，方案 A 的排名保持稳定，说明模型结果具有较强的稳健性。
```

## 4. 理论与结果的配套关系

- 理论部分提出「用什么方法、为什么用、怎么做」。
- 结果部分展示「用该方法后得到了什么、说明了什么」。
- 两者之间必须能一一对应，避免理论和结果脱节。
- 若结果与理论预期不符，应在结果部分分析原因，而不是修改理论部分的表述来迎合结果。

## 5. 常见问题

| 问题 | 正确做法 |
|------|----------|
| 理论部分只有文字，没有图表 | 补充流程图、算法流程图或算法文字图 |
| 结果部分只有数据，没有分析 | 每张图表后加分析段落 |
| 结果部分用流程图展示 | 改为折线图、柱状图、散点图、热力图或表格 |
| 理论部分堆砌大量公式 | 只保留核心公式，其余放入附录 |
| 理论推导过长 | 用图表概括思路，细节放附录 |
| 把算法文字图画成流程图 | 算法运行路径可用流程图，伪代码步骤应使用三线表 |
