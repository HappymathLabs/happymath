# 国赛结果部分图表绘制参考

结果部分图表用于展示模型求解后的数据、结论和洞察。国赛结果图表的核心原则是：**清晰、简洁、黑白线条、数据为主**。

## 1. 可用图表类型

结果部分只能使用对数据/结果本身进行可视化的图表：

- **折线图**：展示趋势、变化过程、时间序列结果。
- **柱状图/条形图**：展示不同类别之间的对比。
- **散点图**：展示变量之间的关系或分布。
- **饼图**：展示比例构成（慎用，类别不宜过多）。
- **热力图**：展示矩阵型数据或空间分布。
- **箱线图**：展示数据分布与异常值。
- **表格**：展示精确数值、评价结果、参数取值等。

## 2. 禁止使用的图表

结果部分禁止使用以下图表：

- 流程图
- 算法图
- 概念示意图
- 任何用于展示思路而非数据的图表

## 3. 国赛风格配置

- **配色**：优先黑白或单色；若需区分多条曲线，使用不同线型（实线、虚线、点划线）或不同标记（圆点、方块、三角形）。
- **背景**：白色背景，无网格或浅灰色网格。
- **字体**：中文宋体 / 英文 Times New Roman，字号与正文协调。
- **线条**：清晰、不过细。
- **无装饰**：避免阴影、渐变、3D 效果。

## 4. matplotlib 示例配置

```python
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei']  # 中文显示
plt.rcParams['axes.unicode_minus'] = False

fig, ax = plt.subplots(figsize=(6, 4))
ax.plot(x, y1, 'k-', marker='o', label='方案 A')   # 黑色实线
ax.plot(x, y2, 'k--', marker='s', label='方案 B')  # 黑色虚线
ax.set_xlabel('参数 x', fontsize=11)
ax.set_ylabel('指标 y', fontsize=11)
ax.set_title('不同方案指标对比', fontsize=12)
ax.legend(frameon=False)
ax.grid(True, linestyle=':', linewidth=0.5)
plt.tight_layout()
plt.savefig('images/problem1_result.png', dpi=150)
```

## 5. 表格规范

- 所有表格必须使用 **三线表**。
- 表标题置于表上方，格式「表 章-序号  表名」。
- 列对齐：数值列右对齐，文本列左对齐。
- 不要加竖线，不要加额外横线。

示例 markdown 表格：

```markdown
表 1-1  各方案评价结果

| 方案 | 得分 | 排名 |
|------|------|------|
| A    | 0.85 | 1    |
| B    | 0.72 | 2    |
```

## 6. 图表分析文字

每张图表后必须紧跟一段分析文字，内容应包括：

1. 图表展示了什么数据。
2. 关键数值或趋势是什么。
3. 这些结果对当前问题有何意义。
4. 是否验证了理论部分的预期。

示例：

```markdown
![图 1-2 不同方案指标对比](images/problem1_result.png)

由图 1-2 可知，随着参数 x 的增大，方案 A 的指标 y 呈单调上升趋势，而方案 B 在 x > 0.8 后趋于平稳。在 x = 1.0 处，方案 A 的 y 值为 0.85，高于方案 B 的 0.72，说明方案 A 在该场景下更优。
```

## 7. 常见问题

| 问题 | 正确做法 |
|------|----------|
| 结果图使用彩色配色 | 改为黑白或单色方案 |
| 图中缺少轴标签 | 补充 x 轴、y 轴标签和单位 |
| 多个数据系列无法区分 | 使用不同线型/标记 |
| 表格有竖线 | 删除竖线，使用三线表 |
| 图表后没有分析 | 补充分析段落 |

## 8. 输出方式

1. 使用 Python matplotlib / R ggplot2 / Excel 等工具生成图片。
2. 保存为 PNG，分辨率不低于 150 dpi。
3. 放入 `images/` 目录。
4. 在 md 中引用并紧跟分析文字。
