# HappyMath 文档

欢迎来到 **HappyMath** 官方文档！

HappyMath 是一个面向数学建模、科学计算与机器学习的 Python 库，致力于通过高层次的统一接口降低用户的学习成本。它特别适合数学建模竞赛、应用数学研究以及快速原型开发。

## 核心模块

HappyMath 目前包含四大核心模块：

- **AutoML**：自动化机器学习，支持分类、回归、聚类、异常检测与时序预测
- **Decision**：多准则决策分析（MCDM），集成 80+ 种权重计算、排序与模糊决策算法
- **DiffEq**：微分方程统一求解接口，支持常微分方程（ODE）与偏微分方程（PDE）
- **Opt**：数学优化框架，支持单目标/多目标、线性/非线性、代数与微分代数（DAE）优化问题

## 设计哲学

HappyMath 的核心设计理念是：**用统一、简洁的高层接口封装底层复杂的数学工具链**。用户无需深入了解 PyCaret、SciPy、SymPy、Pyomo、Pymoo、py-pde 等库的具体用法，即可快速完成从数据到模型、从方程到解、从决策到优化的完整流程。
