# AutoML 文档阅读指南

本目录是 HappyMath AutoML 模块的完整使用说明。编写 AutoML 相关代码前，必须先阅读完本目录下所有文档，避免把 PyCaret 的工作流、HappyMath 的封装接口和高级集成步骤混在一起。

## 推荐阅读顺序

1. `README.md`

   先读本文件，了解文档结构、阅读顺序和编码前置要求。

2. `quickstart.md`

   快速建立正确的工作流：什么时候只需要 `compare()`，什么时候才需要 `tune()`，什么时候才使用 `ensemble()`、`blend()`、`stack()`。这是日常使用 AutoML 模块时最先参考的文件。

3. `api.md`

   系统阅读每个类和接口的参数、设计思想、返回形式和输出表结构。尤其要读完 `scores()` 的各个 `mode`，因为不同评估方式适用于不同数据量、测试集条件和任务类型。

4. `examples.md`

   查看按问题类型组织的完整示例。示例都使用 HappyMath 接口表达 PyCaret 官方工作流，包括基础比较、调参、融合/堆叠、预测、评分表、聚类、异常检测和时序预测。

## 每个文件的含义

| 文件 | 作用 |
|---|---|
| `README.md` | 文档入口和阅读顺序说明。 |
| `quickstart.md` | 面向实际建模的快速决策指南，强调不同问题选择不同接口。 |
| `api.md` | 接口级参考文档，说明参数、返回值、输出列和设计思想。 |
| `examples.md` | 可执行示例集合，把 PyCaret 官方调用方式映射为 HappyMath 接口。 |

## 编写代码前必须确认

- 已阅读本目录下全部文档，而不是只复制某个示例片段。
- 已明确当前任务类型：分类、回归、聚类、异常检测或时序预测。
- 已明确目标：基础模型比较、超参数调优、集成学习、预测、评分表输出或模型保存。
- 已确认 `compare()` 不会自动调参；需要调参时必须显式调用 `tune()`。
- 已确认简单比较任务不默认调用 `ensemble()`、`blend()` 或 `stack()`。
- 已根据任务目标选择合适指标，例如分类 `Accuracy/F1/AUC`，回归 `MAE/RMSE/R2`，时序 `MASE/RMSE/SMAPE`。
- 已根据数据情况选择 `scores()` 的 `mode`，尤其区分 `custom`、`kfold`、`holdout` 和 `train-only`。
- 运行示例或测试时使用 conda 的 `happymath` 环境。
